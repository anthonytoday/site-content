{%- comment -%} "Last updated" for a product page. Reads the site build time, so it reflects the last time the site was actually regenerated rather than a date hardcoded in 24 files that quietly goes stale. GitHub Pages rebuilds on every push, so this stays honest. A template can override it with an explicit `updated:` string in _data/templates.yml when that particular template gets a real content update. {%- endcomment -%} {%- assign L = "en" -%}{%- assign catalogue_src = include.catalogue | default: site.data.templates -%} {%- assign wanted = include.id | default: page.template_id -%} {%- assign t = nil -%} {%- for x in catalogue_src -%}{%- if x.id == wanted -%}{%- assign t = x -%}{%- endif -%}{%- endfor -%} {%- if t.updated -%}{{ t.updated }} {%- else -%} {%- assign mm = site.time | date: "%m" -%}{{ site.time | date: "%b %Y" }}{%- endif -%}
